# Two Fishes

An astrology app prototype in a single page (`index.html`):

- **Birth Chart**: a clickable wheel showing placements, signs, houses and aspects.
- **Transits**: your whole birth chart with the sky for any date around it. Each transit is read through houses, rulerships and natal aspects. Includes a house "weather" view and a 12-month timeline of slow transits.
- **Learn & Play**: quiz games for learning glyphs, rulers, elements, houses, aspects and your own chart.

Open `index.html` in a browser to run it. Planet positions come from [Astronomy Engine](https://github.com/cosinekitty/astronomy), loaded from a CDN.
